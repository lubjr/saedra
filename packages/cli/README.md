# @usesaedra/cli

CLI-first architectural memory and AI-powered code review for your codebase.

## Install

```bash
npm install -g @usesaedra/cli
```

This installs the `saedra` command globally.

## Quick start

```bash
saedra login              # authenticate with your Saedra account
saedra init                # link the current repo to a Saedra project
saedra context              # print a compressed architecture context (great for AI prompts)
saedra review                # validate your diff against violation rules and active decisions
```
